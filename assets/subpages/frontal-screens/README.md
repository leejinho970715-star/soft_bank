# 정면 제품 화면 검수

2026-09-23 수정 기준:

- OmniEsol, Amaranth 10, WEHAGO, 비영리 페이지의 기울어진 생성형 목업을 실제 화면 원본으로 교체합니다.
- OmniEsol·Amaranth 10·비영리의 모니터 프레임은 CSS로 정면에 배치합니다. 화면 픽셀에는 원근 변형을 적용하지 않습니다.
- WEHAGO는 사용자가 제공한 정면 모니터·모바일 복합 이미지를 우선 사용합니다.
- ONE AI 설명 이미지도 생성형 보정본 대신 정확한 문구가 있는 원본을 사용합니다.
- 가로 3,840px PNG와 WebP를 제공합니다. Lanczos 리샘플링과 약한 윤곽 보정만 사용하며, 원본 알파 채널을 유지합니다.
- 작은 원본의 글자는 새로 만들어 넣지 않습니다. 확대가 원본에 없는 디테일을 복원한다는 의미는 아닙니다. 화면 이미지를 선택하면 전체 크기로 볼 수 있습니다.
- `manifest.json`은 원본 경로·크기·SHA-256과 결과물 크기를 기록합니다. `tools/prepare-frontal-screens.py`로 재생성할 수 있습니다.
- PMS 7개 업무 화면과 업무 흐름도, IFRS18 3개 화면은 각 전용 폴더의 고해상도 원본을 유지합니다.
- 화면이 아닌 제품 로고와 3D 상징 일러스트는 목업 교체 대상에서 제외합니다.
