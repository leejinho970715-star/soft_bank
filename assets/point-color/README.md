# 3D icon point colors — 2026-10-12

Production PNGs were edited individually with the built-in `image_gen` tool.
Original subjects, blue/white materials and compositions are retained, with
limited golden yellow and coral red accents. Files have genuine RGBA transparency.
Brand logos, actual product screenshots and all main/sub visual assets are excluded.

`manifest.json` contains the original asset, final workspace path, native
dimensions and complete final prompt for every edited asset. The same metadata
is saved beside each PNG as `.png.json`. All production outputs are in this
directory, mirroring their original paths below `assets/`.

`tools/apply-point-colors.mjs` applies this mapping after page generation, removes
obsolete WebP sources and refreshes product stylesheet versions. PMS feature
cards use white HTML backgrounds and unchanged selectable Korean text, with
these transparent 3D icons, so their labels are not regenerated by AI.
