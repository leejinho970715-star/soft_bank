    간이지급명세서는 지급 기준으로 집계되기 때문에 발생하는 정상 동작입니다.

    2. 하반기 신고 시 처리 방법 - 당해 귀속분을 다음 해 1월에 지급한 경우, 12월 지급분에 포함하여 하반기 신고로 반영합니다. 

    ※ 귀속 기준과 지급 기준을 혼동하지 않도록 주의해 주세요.

    상여 지급내역이 급여 지급내역으로 집계되는 경우, 어떻게 처리하나요?

    상여 항목의 코드 구분이 잘못되면 급여지급내역으로 집계됩니다. 

    1. [기초코드설정] 등록 시 영문자와 숫자를 조합하여 3자리로 입력합니다. 
    - P : 급여 
    - PX : 근로소득 제외 
    - V : 상여 
    - ZY : 사업자부담금 

    2. 상여 항목은 반드시 V코드로 등록해야 상여지급내역으로 집계됩니다. 
    3. P코드로 지급된 상여는 급여지급내역으로 집계되므로 코드를 V로 정정한 후 재계산하시기 바랍니다. 

    ※ 퇴직연금 산정 시 상여 반영 방식에 따라 계산이 달라질 수 있으니 [퇴직연금 산정 기준] 설정도 함께 점검해 주세요.

    부가세 예정신고 누락분은 어떻게 반영하나요?

    전표입력과 부가세신고서에서 순차적으로 반영합니다. 

    1. [전표입력]에서 예정신고 누락 전표를 작성합니다. 
    2. 작성 시 '예정신고누락일'에 신고기준일(확정신고 기간)의 일자를 입력합니다. 
    3. [부가세신고서]에서 '새로 불러오기'를 실행하면 누락분이 자동 반영됩니다. 
    4. 필요 시 [가산세] 항목에 금액과 세액을 직접 입력합니다. 

    ※ 가산세 판단이 필요한 경우 국세청 또는 관할 세무서에 확인하시기를 권장드립니다.

    Amaranth10 부가세신고 시 오류메시지 및 해결방안이 궁금합니다.

    부가세신고서 검증 시 발생하는 대표 오류와 처리 방법입니다. 

    1. 오류-1: 사업장관리 필수 항목 누락 → [기초정보관리] > [사업장관리]에서 누락 항목을 채워 주세요. 
    2. 오류-2, 3: 공제받지못할매입세액명세서 불일치 → 매입 전표의 세무구분과 명세서 금액을 재대사합니다. 
    3. 오류-4, 5: 신용카드/기타 매출세액 오차 → [부가세신고서] 상 신용카드매출전표수취명세서와 매출 전표의 합계를 확인합니다. 
    4. 오류-6: 의제매입세액 업종코드 미등록 → 거래처 원장에서 의제매입 대상 업종코드를 등록합니다. 
    5. 오류-7, 8: 신용카드수취명세서 금액 불일치 → 카드/현금영수증 수취내역과 전표를 재정렬합니다. 
    6. 오류-9, 10: 현금매출/사업장현황명세서 제출 필수 → 해당 부속서식을 작성합니다. 
    7. 오류-11: 영세율 첨부서류 미작성 → 수출/영세율 관련 첨부서류를 등록합니다. 

    ※ 세법 판단이 필요한 경우 관할 세무서 또는 국세청 상담을 함께 참고해 주세요.
